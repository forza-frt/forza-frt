# Radar Map

Мобильное веб-приложение (PWA) для водителей: карта города, камеры контроля скорости, ограничения скорости на участках дорог, текущая скорость по GPS и следующая камера по ходу движения. Открывается в Safari на iPhone и добавляется на главный экран как обычное приложение.

Первый город — Рига. Также в списке другие города Латвии: Юрмала, Елгава, Даугавпилс, Лиепая, Вентспилс, Валмиера.

---

## Запуск одной командой

Нужен Node.js 20+ (проверено на 22).

```bash
npm install
npm start          # сборка + сервер на http://localhost:8787
```

Режим разработки: `npm run dev` (Vite на :5173). Для kartes.lv дополнительно запустите `npm run dev:server`.

| Команда | Что делает |
|---|---|
| `npm start` | собирает PWA и запускает сервер (`dist/` + `/api`) |
| `npm run dev` | dev-сервер Vite с hot reload |
| `npm test` | unit-тесты (Vitest) |
| `npm run test:e2e` | сквозной тест сборки в мобильном Chromium (сначала `npm run build`) |
| `npm run typecheck` | проверка типов |

## Как открыть на iPhone

**Важно:** Safari даёт доступ к геолокации только по **HTTPS**. Адрес вида `http://192.168.x.x:8787` откроет карту и камеры, но без GPS-скорости.

Способы получить HTTPS:

1. **GitHub Pages (проще всего, бесплатно).** В репозитории уже есть `.github/workflows/pages.yml`.
   - GitHub → Settings → Pages → Source: **GitHub Actions**.
   - Влейте код в ветку `main`. Через 1–2 минуты приложение будет доступно по адресу `https://<user>.github.io/<repo>/`.
   - Без сервера работает всё, кроме kartes.lv: карта, камеры и ограничения из OpenStreetMap, GPS.
2. **Туннель к своему компьютеру:** `npm start`, затем `npx localtunnel --port 8787` или `cloudflared tunnel --url http://localhost:8787`. Откройте выданный `https://` адрес на телефоне.
3. **Любой хостинг Node.js** (Render, Railway, Fly.io, VPS): команда сборки `npm install && npm run build`, запуска `npm run serve`, переменные из `.env.example`.

### Установка на главный экран

1. Откройте адрес приложения в **Safari**.
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран "Домой"»**, затем **«Добавить»**.
4. Запустите Radar Map с иконки: приложение откроется на весь экран, без панели Safari.
5. При первом запуске разрешите доступ к геолокации. Если вы её запретили: Настройки → Конфиденциальность и безопасность → Службы геолокации → Safari (или Radar Map) → «При использовании».

Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Пока GPS включён, приложение не даёт экрану погаснуть (Wake Lock, iOS 16.4+). Когда экран заблокирован, iOS не передаёт веб-приложениям координаты, поэтому в фоне предупреждения не работают.

## Источники данных: что реально работает

| Данные | Источник | Статус |
|---|---|---|
| Подложка карты (тёмная) | CARTO Dark Matter (на данных OpenStreetMap) | ✅ работает, без ключа |
| Стационарные камеры | OpenStreetMap: `highway=speed_camera` + отношения `type=enforcement` (`maxspeed`, `average_speed`) через Overpass API | ✅ работает, без ключа, загружается прямо на телефоне |
| Ограничения скорости на участках | OpenStreetMap: теги `maxspeed`, `maxspeed:forward/backward` на дорогах | ✅ работает, без ключа |
| Камеры kartes.lv (в т.ч. возможные зоны мобильных камер) | `developers.kartes.lv/en/speedcameras` | ⚠️ адаптер готов, нужен ключ и URL, **формат ответа не проверен** (см. ниже) |
| Пробки kartes.lv | `developers.kartes.lv/en/trafficjam` | ❌ не реализовано |
| Возможные зоны мобильных камер | в OSM таких данных нет; появятся только из источника, который их публикует (kartes.lv) | ⚠️ зависит от kartes.lv |

### Почему kartes.lv не проверен

Приложение собиралось в изолированной облачной среде, сетевая политика которой блокировала `developers.kartes.lv`, Overpass и тайлы OSM. Поэтому:

- я **не смог прочитать** документацию и условия использования API kartes.lv и не делал к нему ни одного запроса;
- адрес API **не зашит в код** и задаётся в `.env`;
- функция `server/kartes.ts → normalize()` читает распространённые форматы (GeoJSON или массив объектов с `lat/lon`) и сопоставляет поля по названиям. Камеру с нераспознанным типом она помечает «Тип не указан источником» и ничего не угадывает. Координаты вне Латвии (например, в проекции LKS-92) она отбрасывает, а не рисует в неверном месте;
- **фиктивных данных нет.** Пока источник не подключён, в «Слоях» написано «kartes.lv не подключён», а на карте только камеры из OSM.

**Как подключить kartes.lv:**

1. Получите API-ключ на https://developers.kartes.lv/ (Jāņa sēta). Там же прочитайте условия использования.
2. `cp .env.example .env` и заполните:
   ```
   KARTES_API_KEY=ваш_ключ
   KARTES_SPEEDCAMERAS_URL=<URL из документации>  # плейсхолдеры: {key} {south} {west} {north} {east}
   ```
3. `npm start`. Проверка: `http://localhost:8787/api/health` → `"kartesConfigured": true`.
4. Если поля ответа называются иначе, поправьте `normalize()` в `server/kartes.ts`. Тесты для него лежат в `tests/kartes.test.ts`.
5. Если фронтенд размещён на GitHub Pages, а сервер в другом месте, задайте `VITE_API_BASE=https://ваш-сервер`. На сервере тогда укажите `CORS_ORIGINS=https://<user>.github.io`.

Ключ хранится **только на сервере**: браузер обращается к `/api/kartes/speedcameras`, а сервер подставляет ключ и кеширует ответ (по умолчанию 60 мин).

### Как приложение обращается с данными

- **Камеры не выдумываются.** На карте только объекты, которые есть в источнике.
- **Ограничение у камеры** берётся по приоритету: тег камеры → тег отношения `enforcement` → тег участка дороги в радиусе 30 м (в карточке подписано «по данным участка дороги»). Если ни одного нет, показывается «Нет данных».
- **Ограничения на дорогах** показываются, только если они явно указаны в OSM. Коды зон вроде `LV:urban` (= 50) — это явное указание картографа, и они переводятся по ПДД. Участки без тега рисуются серым пунктиром, при нажатии — «Нет данных».
- **Направление контроля** показывается так, как его указывает источник. Если его нет — «Не указано источником».
- **Мобильные зоны** — отдельный тип со своим маркером (жёлтый пунктир) и подписью «возможна». Приложение никогда не утверждает, что камера стоит там сейчас.
- **Кеш:** камеры города хранятся на устройстве и обновляются не чаще раза в 12 часов, или по кнопке «Обновить» в «Слоях». Если обновить не удалось, старые данные остаются, а сверху появляется «Не удалось обновить. Показаны данные от …».
- **Полнота OSM** зависит от картографов-волонтёров: какие-то камеры могут отсутствовать. Ориентируйтесь на дорожные знаки.

### API-ключи

| Ключ | Нужен? | Где взять |
|---|---|---|
| — (OSM, Overpass, CARTO) | нет | бесплатно, с атрибуцией (выводится на карте) |
| `KARTES_API_KEY` | только для kartes.lv | https://developers.kartes.lv/ |

Overpass — общественный сервис с правилами честного использования. Приложение снижает нагрузку: камеры кешируются на 12 ч, дороги загружаются сеткой ячеек по ~1,5 км, и уже загруженные ячейки не запрашиваются повторно. Если основной сервер не отвечает, используются запасные (`VITE_OVERPASS_URLS`).

## Функции

- Тёмная карта на весь экран, перемещение и масштабирование пальцами.
- Камеры: стационарные (красные), контроль средней скорости (фиолетовые), возможные мобильные зоны (жёлтый пунктир). На маркере — ограничение. Нажатие открывает карточку: дорога, ограничение, расстояние, тип, направление, источник, время обновления.
- Ограничения скорости: участки раскрашены по разрешённой скорости (легенда в «Слоях»). Видны с масштаба 13, загружаются с 14. Нажатие на участок показывает название, ограничение (с учётом направления), длину, камеры на участке и ссылку на OSM.
- Текущая скорость по GPS. Используется скорость, которую сообщает устройство, а если её нет — расстояние между точками. Значение сглаживается, стояние на месте показывается как 0. При плохой точности появляется подпись «слабый сигнал GPS».
- Текущее ограничение: дорога, на которой вы находитесь, с учётом курса (на перекрёстке выбирается дорога по направлению движения) и разных ограничений по направлениям.
- Превышение: красная рамка панели, красная цифра скорости и «Превышение скорости». Без мигания.
- Следующая камера: в движении — только камеры впереди (сектор ±35°, до 3 км). Камеры позади не показываются. На месте показывается «Ближайшая камера» в пределах 1,5 км. Направление самой камеры при отборе не используется, потому что источники его редко указывают.
- Кнопка «Моё местоположение» включает следование за автомобилем. Если сдвинуть карту пальцем, следование отключается.
- Слои: стационарные камеры, мобильные зоны, ограничения скорости, названия дорог.
- Выбор города.
- Без геолокации всё, кроме скорости, продолжает работать.
- PWA: работает офлайн-оболочка, просмотренные тайлы кешируются (до 1500 шт., 14 дней).
- Приватность: координаты не покидают устройство. Сервер их не получает и не хранит, нет регистрации, рекламы и аналитики.

## Архитектура

```
src/
  pages/MapPage.tsx            главный экран, состояние выбора, связывает всё
  components/
    MapView.tsx                Leaflet-карта, подложка, слой подписей, следование
    CameraLayer.tsx            маркеры только в видимой области (меньше DOM)
    CameraMarker.tsx           маркер камеры (кешированные DivIcon)
    SpeedLimitLayer.tsx        участки дорог: один canvas, императивный Leaflet
    UserLocationMarker.tsx     позиция и стрелка курса
    CameraDetails.tsx / RoadDetails.tsx   карточки
    BottomPanel.tsx            скорость · ограничение · следующая камера
    TopBar.tsx, LayersSheet.tsx, CitySheet.tsx, DataStatus.tsx, Sheet.tsx, SpeedSign.tsx, LocationButton.tsx
  services/
    overpass.ts                клиент Overpass API, запросы, запасные серверы
    osmParse.ts                OSM → Camera / RoadSegment
    cameraService.ts           провайдеры (osm, kartes), слияние, кеш
    roadService.ts             загрузка дорог по ячейкам
    speedService.ts            скорость, текущее ограничение, камеры впереди
  hooks/  useGeolocation, useCameras, useRoads, useSettings, useWakeLock
  utils/  geo.ts (расстояния, азимуты), maxspeed.ts, format.ts
  config/cities.ts             города и их источники
server/
  index.ts                     Express: статика + /api/kartes/speedcameras (ключ, кеш)
  kartes.ts                    адаптер kartes.lv
```

**Почему так:**

- Leaflet + OpenStreetMap, как и просили. Для этой задачи он лёгкий и быстрый на iPhone.
- Дороги рисуются на одном canvas, а не тысячами React-компонентов.
- Для основной функциональности backend не нужен: OSM-данные публичные, Overpass поддерживает CORS. Сервер существует только чтобы спрятать ключ kartes.lv и кешировать его ответы.
- PostgreSQL/PostGIS не используются: хранить пока нечего, а кеш на устройстве и в памяти сервера покрывает задачу. Они понадобятся, если появится собственная база камер.

### Добавить город

Добавьте запись в `src/config/cities.ts`. Например, Москва:

```ts
{ id: 'moscow', name: 'Москва', country: 'RU', center: [55.7558, 37.6173], zoom: 12,
  bbox: [55.49, 37.29, 56.01, 37.97], sources: ['osm'] },
```

Новый источник (например, официальный реестр камер другой страны) — это объект `CameraProvider` в `cameraService.ts`. Если он требует ключ, нужен ещё маршрут на сервере. Если в источнике нет камер для города, приложение пишет «Камеры для этого города пока недоступны».

## Что проверено

Всё ниже реально запускалось в облачной среде разработки:

- `tsc`: без ошибок. `npm run build`: сборка, manifest и service worker генерируются.
- **35 unit-тестов (Vitest):**
  - расстояния, азимуты, точка–линия;
  - разбор `maxspeed` (числа, mph, `LV:urban`, `none`, двойные значения);
  - разбор камер из OSM: ограничение не выдумывается, тип average_speed определяется;
  - оценка скорости (по GPS / по точкам / на месте / нет данных);
  - камеры впереди и позади;
  - выбор дороги на перекрёстке и ограничение по направлению;
  - слияние источников (мобильные зоны не сливаются);
  - адаптер kartes.lv.
- **Сквозной тест (`npm run test:e2e`, 26 проверок)**: production-сборка, мобильный Chromium с размером экрана iPhone 13, эмуляция движения по GPS:
  - карта, маркеры, скорость ≈45 км/ч, ограничение 50, следующая камера впереди (а не позади);
  - «В пределах ограничения», затем ≈78 км/ч → предупреждение о превышении;
  - карточка камеры, слои и их переключение, участки дорог на canvas;
  - запрет геолокации → «Скорость недоступна», а карта работает;
  - ошибка API без кеша → сообщение и ноль камер;
  - ошибка API с кешем → старые данные с предупреждением;
  - manifest, service worker и иконка отдаются.

**Чего я не мог проверить** (сеть среды сборки закрыта):

- реальные ответы Overpass для Риги — в e2e-тесте Overpass подменён тестовым набором `tests/fixtures/overpass-test.json`, который используется **только в тесте**;
- загрузку тайлов карты;
- API kartes.lv;
- работу на физическом iPhone и установку на главный экран в Safari. Manifest, иконки и meta-теги для iOS настроены, но это стоит проверить на устройстве.
